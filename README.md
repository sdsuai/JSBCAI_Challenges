# VirtualTester Setup Instructions

## 1. Download the Software
- Go to: [https://3dexperience.virtualtester.com/#home](https://3dexperience.virtualtester.com/#home)
- Download VirtualTester

## 2. Install the Application
- Run the installer and complete the installation process

## 3. Log in and Configure
- Open VirtualTester
- Log in to your account or create a new account
- Follow the on-screen setup instructions

## 4. Start the Practice Exam
- Select **SolidWorks** from the available options
- Choose **Sample CSWA**
- Click **Start** to begin the exam

## 5. Submit Your Results
- Once completed, take a screenshot of your final score/report
- Submit the screenshot
